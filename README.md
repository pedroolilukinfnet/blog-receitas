# blog-receitas

O projeto é um caderno de receitas feito em Gatsby.

A página inicial lista as receitas, e cada receita é um arquivo Markdown que gera uma rota própria. O site tem cabeçalho, rodapé e formulário de contato com validação.

As receitas ficam em `content/receitas`. Cada arquivo vira uma página em `/receitas/slug`.

- Site: https://blog-receitas.netlify.app
- Repositório: https://github.com/pedroolilukinfnet/blog-receitas

Pra rodar:

```
npm install
npm run develop
```
